## What this is

A lightweight desktop browser shell written in Rust, using Servo
(https://servo.org) as the embedded rendering engine, focused on
keyboard-first navigation and a command palette. Not a Chrome/Firefox
competitor — a focused tool for a specific audience. See AGENTS.md for
the full framing and non-goals.
